About this playground

  
LLM API Playground is a free, single-page tool for testing chat-completion APIs from your browser. It has presets for Inception (Mercury), Google AI Studio (Gemini), OpenRouter, Together AI and OpenAI, plus a custom mode that detects the base URL, authentication style and token parameter of any OpenAI-compatible service, including local servers such as Ollama and LM Studio. It can check which models a key can actually use, stream responses, test tool calling and structured output, and measure latency and throughput.

  
What you can use it for

  
    
    
  • Check whether an API key works and list which models it can actually use, with a live availability probe.
    • 
    
  • Compare latency, time to first token and tokens per second across models and providers.
    • 
    
  • Test streaming, tool (function) calling, JSON mode and JSON-schema structured output.
    • 
    
  • Try reasoning-effort settings, sampling parameters and provider-specific flags without writing code.
    • 
    
  • Connect any OpenAI-compatible endpoint, including Groq, Mistral, DeepSeek, xAI, Fireworks, Ollama and LM Studio, by pasting a URL or a cURL command.
    • 
    
  • Copy the exact request as cURL, Python or JavaScript once it works.
    • 
  

  
There is no backend and no analytics. Requests go directly from your browser to the provider you choose. API keys are kept only in your browser’s storage, optionally encrypted with a passphrase. This project is not affiliated with any of the providers named above.
